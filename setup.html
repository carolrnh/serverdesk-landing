Setup guide

ServerDesk is a Discord utility for paid course and cohort communities: welcome, /faq, and /ask → staff. Hosted plan is $19/mo per server.

Hosted setup (recommended)

  1. Pay for hosted ServerDesk: $19/mo checkout.
  2. After payment you’ll get an invite link and a short provision email.
  3. Invite the bot with scopes bot and applications.commands.
  4. In your server (as an admin), run: 
    /setup welcome_channel:#welcome staff_channel:#staff-help staff_role:@Staff
  5. Try /faq and /ask How do I access Week 1?.

What each command does

  • /setup — welcome channel, staff channel, staff role, optional welcome text
  • /faq — answers from your FAQ knowledge base
  • /ask — private staff thread (or staff channel) for real questions

Permissions to allow

View Channels, Send Messages, Embed Links, Create Public/Private Threads, Send Messages in Threads. Manage Threads is optional. Do not require Mention Everyone.

Intents

Enable Server Members Intent so welcome-on-join works. Message Content Intent is not required (slash commands only).

What ServerDesk does not do

  • No mass DMs
  • No invite bumps or growth spam
  • No member-list scraping for marketing
