Setup guide

ServerDesk is a Discord utility for paid course and cohort communities: welcome, /faq, and /ask → staff. Hosted plan is $19/mo per server.

Hosted setup (recommended)

  1. Subscribe — $19/mo checkout via Stripe. Cancel anytime.
  2. Check your email — after payment we email your Discord invite link and a short provision note. You do not create a Discord app yourself.
  3. Add ServerDesk — open the emailed invite and add the bot to your server (as an admin).
  4. Configure — in your server, run: 
    /setup welcome_channel:#welcome staff_channel:#staff-help staff_role:@Staff
  5. Try /faq and /ask How do I access Week 1?.

What each command does

  • /setup — welcome channel, staff channel, staff role, optional welcome text
  • /faq — answers from your FAQ knowledge base
  • /ask — private staff thread (or staff channel) for real questions

Permissions the invite will request

When you approve the emailed invite, Discord may ask for: View Channels, Send Messages, Embed Links, Create Public/Private Threads, Send Messages in Threads. Manage Threads is optional. Mention Everyone is not required.

Self-host

Prefer to run the open MVP yourself? Create your own Discord application in the Developer Portal, add a bot, enable Server Members Intent (welcome-on-join), and invite with scopes bot + applications.commands. Message Content Intent is not required (slash commands only). Then configure channels with /setup as above. Hosted buyers can ignore this section.
